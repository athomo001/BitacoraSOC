Apariencia — Tema de Login

Selecciona el estilo visual que se mostrará en la pantalla de inicio de sesión. El cambio se aplica de inmediato, sin reiniciar el servidor.

🖥 CRT Retro

Estilo terminal retro con grid de fondo, scanlines, texto monoespaciado con glow verde. El diseño original del sistema.

💻 Matrix / Infoflow (Cyberpunk)

Estilo cyberpunk con lluvia tipo Matrix animada, card glassmorphism con borde neón, título con efecto glitch, botones con flecha animada y modal de recuperación con reloj digital en tiempo real.

💻 Moderno / Split-Screen

Diseño profesional premium en pantalla dividida (split-screen). Panel izquierdo con formulario de acceso limpio (soporta MFA y recuperación de contraseña) y panel derecho con fondo arquitectónico corporativo y una lluvia sutil de código Matrix animada.

🎨 Surrealismo Digital

Diseño surrealista y moderno inspirado en el arte digital. Presenta el formulario interactivo en una barra lateral izquierda de altura completa, dejando visible de forma limpia y nítida la imagen del monitor retro iluminado en el paisaje crepuscular de fondo.

🪟 Windows 3.11

Estilo clásico de Windows for Workgroups v3.11. Escritorio verde azulado (Teal) clásico, ventanas grises con bordes biselados 3D retro y Program Manager de fondo.

📟 Unix Terminal (1989)

Estilo consola CLI plana clásica de Unix/Linux. Fondo negro puro, texto de fósforo ámbar (naranja), cursor parpadeante clásico y reloj en tiempo real fijado en 1989.
