📋 Formato de Datos de Asignación

Campos esperados para el registro o importación CSV de turnos:

  • condición: N1, N2, TI, Teletrabajo, Charla/Capacitación (OL), Vacaciones, Trámite Médico o Licencia médica.
  • usuario: Username recomendado; también acepta email o nombre completo. El sistema detecta si es usuario interno o persona externa.
  • fechaInicio / horaInicio: Formato YYYY-MM-DD y HH:MM (ej: 2026-05-26, 09:00).
  • fechaFin / horaFin: Formato YYYY-MM-DD y HH:MM (ej: 2026-06-02, 08:59).
