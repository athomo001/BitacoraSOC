Estas abriendo la pagina como archivo local (file://). Varios navegadores (Chrome, Brave, Edge) bloquean workers, WASM o lectura de recursos de forma que el emulador puede fallar aunque los archivos existan. Sirve la carpeta por HTTP: doble clic en run-local.cmd (recomendado en Windows) o en PowerShell usa python -m http.server 5173. Si usas Node y PowerShell bloquea scripts, ejecuta npx.cmd --yes serve -l 5173 (no npx.ps1). Luego abre http://127.0.0.1:5173 solo con el servidor ya corriendo (si no, veras error -102).
